# NexusRealm

Nexusrealm is a collection of tools for Dungeons & Dragons 5th Edition (2014). Functionality will include a character creator, a rules glossary, homebrew creation, a worldbuilding wiki, and others.

## Getting Started

### Prerequisites

- NodeJS version 20 or higher
- pnpm version 10 or higher
- PostgreSQL 16 or higher (installed separately)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/StormbringerDev/nexusrealm
cd nexusrealm

# 2. Install dependencies
pnpm install

# 3. Build website
pnpm build

# 4. Start NexusRealm
pnpm start
```
